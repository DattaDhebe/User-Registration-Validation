# User Registration Validation · C#

C# regular-expression validation practice with field-level methods and a separate test project.

**CSHARP · DOTNET · REGEX**

## What is included

- Separate validation methods for first name, last name, email, mobile and password fields.
- Example test cases for accepted and rejected input.

| Location | Purpose |
| --- | --- |
| [UserRegistration](UserRegistration) | Validator implementation |
| [TestUserRegistration](TestUserRegistration) | Test project |
| [UserRegistration.sln](UserRegistration.sln) | Solution |

## Getting started

Use an SDK compatible with the target frameworks declared in the project files.

```bash
dotnet test UserRegistration.sln
```

The solution can also be opened in Visual Studio.

## Project status

Learning code with simplified regex rules. It does not implement account storage, password hashing or authentication.

Setup commands are documented from the repository structure; execution has not been revalidated as part of this presentation update.
